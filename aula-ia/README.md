# Interface web da AulaIA

O código React está em `src/App.jsx`. Para testar a versão compilada, siga o [roteiro de execução do projeto](../README.md). Para editar o frontend, execute a API Python na porta 8000, abra outro terminal nesta pasta e rode `npm ci` e `npm run dev`. Para reconstruir o frontend servido pelo Python, execute `npm run build`.
